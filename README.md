# Web Application Development - HW1, HW2, HW3

This repository contains three independent, accessible browser features in one static site:

1. **HW1 - Production Portfolio**: semantic project cards, an accessible detail dialog, keyboard focus trapping, and performance-conscious CSS/JavaScript.
2. **HW2 - Drum Kit Engine**: a contract-first, polyphonic Web Audio drum kit, keyboard repeat throttling, and a timestamped beat recorder.
3. **HW3 - Resilient Event Hub**: UTC-based countdowns, a three-step state-machine form, double-submit prevention, validation, and a documented AI failure audit.

## Run locally

```bash
npm start
```

Open `http://localhost:4173`.

## Verify

```bash
npm test
```

The app deliberately has no build step or third-party runtime dependency.
